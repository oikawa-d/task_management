# APP_TIMEZONEの日境界テストの注意点

## 事象

UTCの日時をそのままローカル日付として期待値に使うと、日末直前と日付切替直後のテストが1日ずれる。

## 原因

日境界の開始時刻は、UTCの入力日ではなく、入力を`APP_TIMEZONE`へ変換した後のローカル日付から求める必要がある。

## 正しい対処

- 境界直前と境界直後のUTC入力を用意する。
- 入力を`APP_TIMEZONE`へ変換したローカル日付を確認してから、期待する開始・終了時刻をUTCへ戻す。
- JSTでは日付開始が前日15:00 UTCになることを含め、境界値をテストする。
