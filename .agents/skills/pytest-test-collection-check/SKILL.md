# pytestパラメータ化テストの収集確認

## 事象

パラメータ化テストのデコレータを追加した際、括弧の閉じ忘れによりpytestのテスト収集がSyntaxErrorで停止した。

## 原因

テストケースの追加後に、対象ファイルの構文確認とpytest収集を実行せず、テスト本体の検証へ進めた。

## 正しい対処

- パラメータ化デコレータの引数リストと閉じ括弧を追加直後に確認する。
- 対象テストを実行する前に `python3 -m py_compile` またはpytestの収集を実行する。
- 構文エラー修正後は対象テストを再実行し、収集件数と成功結果を確認する。
