# シェル検索のパス指定

## 事象

正規表現の括弧を含むファイルパスを、クォートせずにシェルへ渡すと、bashの構文として解釈されて検索コマンドが失敗する。

## 原因

`test_(projects|tasks)_router.py` のようなパスを、ripgrepの引数としてではなく、シェルの構文として評価させていた。

## 正しい対処

- パスの括弧・空白・glob記号を含む場合は、各パスを単引用符で囲む。
- 複数ファイルを正規表現で指定する場合は、パスglobに頼らず `rg` の検索対象ディレクトリと `--glob` を使う。
- 実行前に、コマンドをシェル構文として解釈した場合の意味を確認する。
