# 運用文書の差分適用における注意点

## 事象

長い一行の完全一致を前提にパッチを適用すると、実ファイルの文言との差異によって適用に失敗することがあります。

## 原因

修正対象の全文を事前に確認せず、想定した文言をそのままパッチの一致条件に使用するためです。

## 正しい対処

- `sed` や `nl` で修正対象の前後を確認してからパッチを作成します。
- 長い行は、変更点を含む短い固有の文脈でパッチを適用します。
- 適用後は `git diff --check` と差分内容を確認します。
