# errexit環境の算術演算における注意点

## 事象

`set -e`下で`(( value++ ))`や`(( value-- ))`を単独実行すると、式の評価値が0の場合に終了ステータス1となり、処理が意図せず中断する。

## 原因

Bashの算術コマンドは、式の評価値が0なら終了ステータス1を返す。後置更新は更新前の値を評価結果にするため、0からのインクリメントや1からのデクリメントが`errexit`の対象になる。

## 正しい対処

- 制御用カウンタの更新は`value=$(( value + 1 ))`や`value=$(( value - 1 ))`の代入形式を使う。
- 算術式の真偽を終了ステータスとして使う場合だけ`(( ... ))`を使い、`if`や`while`の条件位置へ置く。
- `set -euo pipefail`を有効にした実スクリプト経由のテストで、正常系の終了コードが0になることを確認する。
