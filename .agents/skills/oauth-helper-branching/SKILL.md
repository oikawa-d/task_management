# OAuth補助処理の分割

## 事象

OAuthレート制限超過時の例外送出が条件分岐の外へずれると、成功系で未定義のTTLを参照して認証処理が503になる。

## 原因

ネストした`try`と`if`を別サービスへ移す際、インデントだけを目視確認して分岐ごとのテストを先に実行しなかった。

## 対処

- レート制限超過、Redis障害、許可時の3経路を個別に確認する。
- `TooManyAttemptsError`は超過分岐内でのみ送出し、許可時はクライアント情報を返す。
- 分割後はOAuthサービスとrouterの既存テストを先に実行してから全体検査へ進む。
